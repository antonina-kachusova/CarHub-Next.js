# CarHub — каталог автомобілів

Вебзастосунок для пошуку та перегляду автомобілів з адаптивним інтерфейсом. Проєкт демонструє мої навички роботи з Next.js, React, TypeScript, зовнішніми API та створення інтерактивних компонентів.

## Що робить проєкт

- Відображає каталог автомобілів із фотографіями, основними характеристиками та розрахунковою вартістю оренди за день.
- Дозволяє шукати автомобілі за виробником і моделлю, пропонуючи підказки під час введення.
- Фільтрує автомобілі за роком випуску та типом пального.
- Відкриває модальне вікно з детальними характеристиками й фотографіями автомобіля з різних ракурсів.
- Показує більше результатів за допомогою кнопки «Show More».
- Зберігає параметри пошуку та фільтрів в URL.
- Адаптує інтерфейс до мобільних пристроїв, планшетів і комп’ютерів.

## Технології, які я використовувала

- **Next.js (App Router)** — маршрутизація, серверні та клієнтські компоненти, API-маршрут для отримання моделей автомобілів.
- **React** — компоненти інтерфейсу, керування станом і обробка взаємодій користувача.
- **TypeScript** — типізація даних, параметрів компонентів і відповідей API.
- **Tailwind CSS** — стилізація та адаптивна верстка.
- **Headless UI** — інтерактивні списки, автодоповнення, модальні вікна й анімації переходів.
- **CarAPI** — отримання даних про автомобілі, їхні моделі та технічні характеристики.
- **IMAGIN.studio** — отримання зображень автомобілів із різних ракурсів.
- **Fetch API** — запити до зовнішніх сервісів.

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрити [http://localhost:3000](http://localhost:3000) у браузері. Для завантаження даних і фотографій потрібне підключення до інтернету.
